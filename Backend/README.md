# Image Post App

## Overview
A learning project focused on backend development. The application allows users to create image posts with captions and displays posts in a feed.

## Features
- Create a post with an image and caption.
- Display multiple posts in a feed.

## Project Status
In Development

## Learning Objectives
- Practice backend development.
- Understand how post data is submitted and processed.
- Learn how images and captions are handled.
- Understand how posts are retrieved and displayed.
- Practice Git and GitHub workflows.
